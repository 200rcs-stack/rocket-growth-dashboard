## 새로고침이 하는 일

1. Downloads의 확인된 파일명 패턴과 raw_data를 스캔합니다. 광고센터 성과·정산 상세 보고서를 새로 내려받았다면 새로고침 때 검증·반영합니다.
2. 파일별 생성시각·해시를 기록하고, 검증된 최신 스냅샷을 사용합니다. 읽기 실패 시 이전 성공 파일과 오류를 표시합니다.
3. 자료실·연결에서 API 키를 연결했다면 공식 로켓그로스 주문·재고·등록상품 API를 다시 호출합니다.
4. 기본 ‘빠른 새로고침’은 1~3번만 수행하며 브라우저를 열거나 엑셀을 새로 다운로드하지 않습니다. ‘화면·엑셀 원본 갱신’을 선택하면 Aside 저장 로그인으로 재고·정산·광고비·반품·이번달 광고 성과 화면을 확인하고 재고·반품·광고 상세 엑셀 3종을 내려받습니다. 파일명과 크기를 확인한 뒤 Downloads에서 raw_data로 복사해 분석합니다. 성공한 화면만 새 시각으로 보관하며 실패한 화면은 마지막 성공값을 유지합니다. 전체 갱신은 하루 한 번 또는 정산 확인 시 실행하는 것을 권장하며, 자동 예약은 아직 설정하지 않았습니다. Chrome 확장 수집기는 현재 기본 경로에서 사용하지 않습니다.

**파일 재스캔은 쿠팡 서버에서 새 파일을 내려받는 것과 다릅니다.** Aside가 화면에 로그인하지 못하면 다운로드 폴더의 마지막 파일만 반영합니다. API도 출고 후 주문만 제공하며 쿠팡의 집계 지연이 있습니다.

Aside의 저장 로그인이 쿠팡윙 로그인 화면에서는 작동하는 것을 검증했습니다. 다만 쿠팡의 비밀번호 재확인·MFA·보안 검사가 나타나면 사용자 개입 없이 통과한다고 보장할 수 없습니다. API는 이 PC 공인 IP가 등록된 허용 목록과 다르면 HTTP 403으로 막힙니다. 쿠팡 공식 안내에 따르면 자체개발 키에는 최대 10개 IP를 등록할 수 있으므로, 장기적인 무인 조회에는 고정 공인 IP를 등록하는 편이 적합합니다.

‘화면·엑셀 원본 갱신’에서 Aside가 종료된 상태이면 설치된 Aside Browser를 다시 실행하고 수집을 재시도합니다. 추가 인증이 생기면 사용자 확인이 필요할 수 있습니다.

2026-10-25 OPEN API 연동 정보에서 기존 IP 106.251.77.5를 유지하고 현재 API가 확인한 접속 IP 119.192.62.87을 추가 저장했습니다. 키는 재발급하지 않았습니다. 21:22~23 KST 공식 API의 HTTP 200 응답과 전체 조회를 확인했습니다. 재고 97개 옵션·최근 30일 결제 주문 72건·등록상품 24개를 저장했고, 대시보드 빠른 새로고침에서도 성공했습니다. 추가 엑셀 다운로드는 실행하지 않았습니다.

## API 연결

쿠팡윙 → 판매자정보 → 추가판매정보 → Open API에서 확인합니다. 2026-10-24 기존 ‘쿠대’ OPEN API 항목을 삭제하고 ‘자체개발 · 왓니몰’ 항목을 새로 발급해 이 PC 공인 IP를 등록했습니다. 플레이오토 키는 유지했습니다. 새 키의 유효기간은 2027-04-22 07:00입니다. 발급 직후에는 HTTP 403이었지만 약 8분 뒤 대시보드 새로고침에서 재고·주문 API 모두 성공했습니다. 등록 IP와 API가 본 접속 IP도 일치했습니다.

키는 채팅에 보내지 않고 대시보드 `자료실·연결 → API 연결`에 연결합니다. 기본은 현재 세션 메모리만 사용합니다. 사용자가 **이 PC에 저장**을 선택하면 Windows 자격 증명 보관소에 저장해 대시보드 재실행 뒤에도 새로고침 시 다시 조회합니다. 연결 해제로 메모리와 저장된 키를 함께 제거할 수 있습니다. 키는 원본 엑셀·JSON·Git에 기록하지 않습니다.

## 정확성 규칙

- ID는 문자열. `.0`와 등급 괄호를 정규화하며 검증되지 않은 ID는 거부합니다.
- `-`와 빈칸을 일괄 0으로 바꾸지 않습니다. 미입력 비용은 이익 계산을 막습니다.
- 반품 파일에는 수량 열이 없어 각 행을 한 상품으로 계산하지 않습니다.
- 월 누적 보관료를 최근 30일 매출에서 그대로 차감하지 않습니다.
- 미회수 후보를 미지급 보상금으로 확정하지 않습니다.
- 현재 반품 스냅샷을 사용합니다. 과거·현재 파일을 누적해 같은 건을 중복 합산하지 않습니다.
- 재고 합산과 과거 비교 시 파일의 전체/부분 추출 범위 확인이 필요합니다.

