# 정확성·보안·AI 보완 기록

적용일: 2026-10-27

## 수정한 문제

- 같은 이름이지만 내용이 바뀐 다운로드가 무시되는 문제: 내용 해시별 보관 및 원본 시각/파일 갱신시각으로 선택.
- 일부 헤더만 확인하던 재고 파서: 관측된 두 헤더 전체 대조. 알려지지 않은 열 구조는 거절.
- 누적 작업이 천 건을 넘으면 새 갱신 요청을 누락하던 문제: 저장소 페이지 전체 조회.
- 요청 본문: JSON 실제 바이트 상한, 형식 검사, 고객·주문 식별키 및 자격증명 키가 있는 스냅샷 거절.
- 원본 파일: 내용 해시 검증과 본인 전용 Sites 접근 경계 유지. 원본에는 식별정보가 있을 수 있으므로 공개 공유 금지.
- CSV: 공백/제어문자 뒤에 수식 시작 문자가 있는 값도 문자열로 내보냄.
- 보상 자료: 거래 없는 새 파일 때문에 이전 보상 거래의 기준 시각이 최신으로 보이는 오해 방지.

## AI와 매뉴얼

- 기존에 승인된 OpenAI 연결 유지. 고객·주문 식별정보와 인증정보는 모델 입력에서 제외.
- 숫자 관측 근거는 검증된 파서에서 생성. AI 출력에 숫자 주장/알 수 없는 근거 ID가 있으면 거절.
- 조언에 추가 확인 자료, 판단 보류 조건, 점검 완료 기준을 추가.
- 자료별 마지막 성공 시각·이번 수집 상태·기준 시각 경과를 같이 표시. 최근 수집은 거래 자체의 실시간성을 의미하지 않음.
- 자료 검증, 재고·입고, 광고·원가, 정산, 반품·보상, 주간 점검의 여섯 운영 절차를 웹 마스터 매뉴얼에 수록.
- 체크 상태는 브라우저에만 저장. 체크 완료는 미수집·오래된 자료를 최신으로 바꾸지 않음.
- 매뉴얼은 이 대시보드의 점검 기준이며 쿠팡 공식 업무 규정이 아님.

## 디자인

- 네이비 탐색 영역, 밝은 배경, 블루 포인트, 충분한 여백과 단순한 카드 구조.
- 본문 16px, 표 본문 14~15px, 보조 설명 대체로 12~14px. 기존 모바일의 8~10px 주요 설명 제거.
- 작은 모바일에서는 지표 카드를 한 열로 배치해 긴 금액이 잘리지 않도록 함.
- 모바일 메뉴·체크리스트·근거 확인과 모션 감소 설정 지원.

## 검증과 남은 제한

- 관련 테스트 45개 통과. 기존 Streamlit 브라우저 스모크 1개는 이번 테스트 실행에서 제외.
- 실제 AI 응답 세 카드의 검토 필드 확인 및 숫자/근거 검증 통과.
- 실제 보관 재고 원본의 헤더 검증 및 요청 크기/형식/식별정보 차단 회귀 테스트.
- 본인 전용 접근 유지. 공개 접근이나 다른 계정에 대한 새 권한은 부여하지 않음.
- Aside의 정산·고객반품 분석 본문 로딩 문제, 기타 미연결 자료, 원가 입력 필요성은 남아 있음. 마지막 성공값과 실패 상태를 표시.
- 이 보완은 확인한 결함에 대한 수정이며 전체 시스템에 취약점이 없다는 인증은 아님.
