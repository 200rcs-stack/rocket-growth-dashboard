# Rocket Desk 화면별 자체 검수 · 2026-10-29

실제 비공개 웹 7개 화면과 매입원가 창을 열어 내용·탐색 흐름을 확인하고, 로컬 개선 화면에서 데스크톱과 모바일(390×844)을 검증했다. 운영자의 사용성 검수이며 초보 사용자 대상 실험이나 만족도 조사 결과는 아니다.

## 화면별 판단과 개선

| 화면 | 사용자가 얻어야 할 판단 | 확인한 부족한 점 | 반영한 개선 |
|---|---|---|---|
| 운영 한눈에 | 돈의 흐름과 우선 확인할 운영 항목 | 수익·우선순위 설명이 반복되어 화면이 길었음 | 수익 인포그래픽·핵심 지표·운영 판단을 유지하고 중복 수익/할 일 패널 제거. 금액 차이·광고·세부 지표는 펼쳐 보기로 보존 |
| 상품·재고 | 입고 후보, 품절, 원가 미입력 파악 | 웹 원가 편집이 있는데 로컬에서만 가능하다고 안내 | 화면 용도·우선 항목·웹 원가 입력 버튼 제공. API 재고/등록상품/변동 원본은 별도로 펼침 |
| 매출·정산 | 같은 기간의 매출·비용과 원가 차감 전 잔액 | 기간이 겹치는 수익 기록이 첫 표로 표시됨. ROAS를 광고 수익률로 표기 | 마지막 검증 기간 인포그래픽을 우선 배치. 이전 기록은 합산 금지 설명과 함께 별도 펼침. ROAS를 광고비 대비 전환매출로 수정 |
| 반품 | 장기 회수·보상 대조 후보 파악 | 과거 월별 반품률이 실무 접수 목록보다 먼저 표시 | 90일 이상 회수·전체 회수·접수 건수와 장기 회수 바로가기 배치. 월별 비율은 별도 펼침. 미확보 자료는 0건으로 표시하지 않음. 경과일은 원본 집계값임을 명시 |
| AI 운영 코치 | 연결 자료에 기반한 다음 행동과 검증 방법 | 이전 분석과 이후 갱신 자료의 차이가 눈에 띄지 않음 | 분석 이후 자료 갱신·원본 재확인·분석 시각 이상을 표시. 현 상황 대화 버튼 추가. 검증 방법/보류 조건/완료 기준은 펼쳐 보기. 유료 분석은 자동 실행하지 않음 |
| 마스터 매뉴얼 | 어떤 결과를 만들고 언제 점검을 끝낼지 이해 | 완료 기준이 긴 절차 뒤에 있었음. 모바일 주제 목록이 길었음 | 완료 기준을 절차 앞에 배치. 모바일은 주제 선택 상자로 즉시 이동. 브라우저 체크 기록의 한계 명시 |

| 매입원가·수익성 | 직접 원가 입력 또는 파일 첨부 후 계산 가능한 범위 확인 | 긴 안내로 첫 입력 칸이 아래로 밀림 | 입력 도움말을 접고 헤더·요약·도구 간격 축소. 빈 검색 결과 안내. 원가 미입력 시 계산 대기를 유지 |

## 공통 개선

- 화면마다 자료의 용도, 읽는 범위, 바로 할 행동을 표시했다.
- 메뉴를 바꾸면 화면 상단으로 돌아간다.
- 큰 목록은 20개씩 추가로 볼 수 있고 전체 자료의 CSV 내보내기는 유지한다.
- 표는 키보드로 가로 스크롤에 접근할 수 있고 긴 상품명·범위 설명을 줄바꿈한다.
- 모바일 크기 변경 시 운영 AI 버튼이 여러 줄로 찌그러지는 현상을 수정했다. 기존 이동 기능은 유지한다.
- 수집 PC 연결이 없으면 자료실의 갱신 요청과 유료 분석 갱신 버튼을 비활성화한다. 저장된 자료 조회는 유지한다.

## 검증

- TypeScript 타입 검사 통과.
- 자동 테스트 51개 통과. 신규 검증: 미확보 반품과 검증된 0건 구분, 반품 집계, 자료 상태 정렬·누락 시각 분리, AI 분석 이후 갱신·노후화·잘못된 시각 처리.
- 실제 Chrome에서 7개 기존 화면을 확인했다. 개선 미리보기에서 반품 90일 필터(7건), 수익 범위 설명, 이전 AI 표시, 원가 입력/분석 전환, 자료실 실패 우선 정렬, 메뉴 전환 상단 복귀를 확인했다.
- 모바일에서 문서 가로 넘침이 없고, 원가 창이 화면 안에 들어오며, 매뉴얼 주제 선택으로 반품 절차가 표시되는 것을 확인했다.
- 실제 발주·광고 변경·보상 요청·유료 AI 생성은 실행하지 않았다. 사용자 원가에 임의 값을 저장하지 않았다.

## 남는 데이터 한계

화면 개선이 자료 누락을 해결한 것은 아니다. 검수 시점 원가 43개 항목이 미입력이고, 정산·월별 반품 분석은 이전 검증 자료다. 문의·리뷰, 미출고·취소·환불 전체, 입고·반출 전체 등 미연결 범위가 남아 있다. 상품별 원가 분석과 윙 수익 기간은 다르므로 자동 합산하지 않는다. 이 자료만으로 확정 순이익·미보상 금액·미래 매출을 단정할 수 없다.
